# hoc

Hobby project for tracking the yearly battles.

## Project structure

```
hoc/
├── app/                # React + Vite + TypeScript app
│   └── src/            # App source code
└── .github/workflows/  # Deploys app/ to GitHub Pages on push to main
```

## Quick start

```bash
cd app
npm ci
npm run dev
```

Then open http://localhost:5173/hoc/#/

## Build

```bash
cd app
npm run build
```
